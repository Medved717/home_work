# Инструкция по применению программы по продуктам.

# Модуль category.py
## Модуль category.py представляет собой класс по принятию экземпляра: наименование категории, описания и списка продуктов, которые являются объектами класса Product и его дочерних классов.

# Модуль product.py
### В данном модуле присутствует класс Product, в котором формируются экземпляры класса со следующими атрибутами: наименование, описание, цена и количество.
### Классметод - new_product позволяет принимать атрибуты для формирования экземпляра класса в виде словаря.
### Метод add позволяет складывать экземпляры классов, а именно стоимость товаров с учетом количества.

# Модуль lawn_grass.py 
### Данный модуль представляет собой класс LawnGrass, который является дочерним классом - Product.
### В данном класса имеются следующие арибуты: наименование, описание, цена, количество, страна, период прорастания семян, цвет.
### Метод add позволяет складывать экземпляры классов, а именно стоимость товаров с учетом количества, используется измененный родительский метод.

# Модуль smartphone.py 
### Данный модуль представляет собой класс Smartphone, который является дочерним классом - Product.
### В данном класса имеются следующие арибуты: наименование, описание, цена, количество, 'эффективность, модель, объем памяти, цвет.
### Метод add позволяет складывать экземпляры классов, а именно стоимость товаров с учетом количества, используется измененный родительский метод.
